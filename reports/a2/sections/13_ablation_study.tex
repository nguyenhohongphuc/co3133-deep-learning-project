\section{Ablation Study}
\label{sec:ablation}

\subsection{Controlled Factor and Hypothesis}

We compare a fixed ImageNet ResNet-50 backbone with one adapted to 30VNFoods. We expect full fine-tuning to improve macro-F1 because the visual cues that distinguish Vietnamese dishes can differ from those learned on ImageNet. In the frozen arm, only the classifier head is optimized. Backbone gradients are disabled and BatchNorm stays in evaluation mode. In the full arm, the backbone receives optimizer updates at $10^{-4}$ and its BatchNorm running statistics update during training. The experiment measures the combined effect of these backbone changes.

Both arms start from the same pretrained weights and use the same classifier architecture, cleaned splits, $224\times224$ inputs, ImageNet normalization, and training augmentation. They share cross-entropy, Adam, weight decay of $10^{-4}$, a head learning rate of $10^{-3}$, and batch size 32. For each of seeds 42, 43, and 44, both arms have a 15-epoch cap and stop after five epochs without improvement in validation macro-F1. The resulting run lengths can differ under that shared stopping rule (Table~\ref{tab:a2-checkpoint-epochs}). Each run is evaluated on the same test images using the checkpoint with the highest validation macro-F1.

The proposal requires a gain larger than the observed spread across three seeds. We quantify spread as the maximum minus minimum test macro-F1 within each arm. The ranges are 0.0044 for frozen and 0.0112 for full. Even the smallest paired gain, 0.1150, exceeds the larger range. The result meets the proposal criterion on these runs. This is a descriptive comparison across three seeds.

Full fine-tuning raises mean training time from 12.13 to 24.97 minutes and mean peak allocated training GPU memory from 0.43 to 2.89\,GiB, with similar measured forward time (Table~\ref{tab:a2-test-compute}). The paired scores are saved in \path{results/a2/tables/a2_test_paired_seed_gains.csv}.
